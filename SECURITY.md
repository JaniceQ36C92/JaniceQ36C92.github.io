# Security

These projects are static, browser-side utilities. They do not have a backend, authentication system, or server-side data store.

- Do not submit passwords, access tokens, identity documents, bank details, private resumes, or confidential business information.
- The job tracker, affiliate scorecard, and software scorecard store user-entered records in browser local storage. Anyone with access to the same browser profile may be able to view them.
- Export and protect backups yourself. Local storage is not encrypted backup storage and does not sync across devices.
- Report a reproducible security issue through the repository's private vulnerability reporting feature if it is enabled. Otherwise, open a minimal issue without including personal or secret data.
