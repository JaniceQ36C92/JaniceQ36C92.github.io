# Remote Job Application Tracker

A standalone, local-first tracker for people applying to technology and remote roles.

## Features

- Record company, job title, location, remote arrangement, and employment type.
- Track location eligibility separately from the word "remote".
- Track application status and follow-up dates.
- Search and filter the application pipeline.
- Export CSV for spreadsheets or JSON for a full backup.
- Import a previous JSON backup.
- Edit or delete records.

## Privacy

Records are stored in local storage in the current browser profile. They are not uploaded or synchronized across devices. Local storage is not encrypted and may be accessible to anyone using the same browser profile. Export a backup before clearing site data.

Do not store passwords, identity documents, bank details, private recruiter credentials, confidential employer information, or other sensitive personal data.

## Responsible job search

A directory listing is a discovery aid, not a guarantee that a vacancy is still open or that a role accepts applicants in every country. Confirm the vacancy, employer identity, location eligibility, and application instructions on the original employer or authorized recruiter website. Never pay to apply for a job.
