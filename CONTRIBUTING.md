# Contributing

Contributions that improve correctness, accessibility, privacy, documentation, and practical usefulness are welcome.

- Keep tools useful without requiring a click to an external website.
- Prefer dependency-free browser code and transparent formulas.
- Do not add tracking, advertising, data collection, or external scripts without a clear need and privacy review.
- Never add credentials, private API keys, user records, or production server code.
- Explain assumptions, limitations, and data handling in relevant documentation.
- Add or update tests when changing calculation logic.
- Keep links relevant to the feature and the reader's next step.

For calculator changes, run npm test in the calculator directory using Node.js 18 or later. Test static pages on desktop and mobile, keyboard navigation, external links, and backup import/export.
